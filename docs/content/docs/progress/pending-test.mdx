## 图片分辨率尺寸表

选择分辨率和宽高比后，W/H 按下表填写，单位为像素。预设尺寸不受「16 倍数对齐」开关影响；该开关只控制手动输入尺寸时的对齐。最终生成尺寸以所选模型的实际输出为准。

| 宽高比 | 1K | 2K | 4K |
| --- | ---: | ---: | ---: |
| **1:1** | **1024 × 1024** | **2048 × 2048** | **2880 × 2880** |
| **2:3** | 1024 × 1536 | 1360 × 2048 | 2336 × 3520 |
| **3:2** | 1536 × 1024 | 2048 × 1360 | 3520 × 2336 |
| **4:3** | 1024 × 768 | 2048 × 1536 | 3312 × 2480 |
| **3:4** | 768 × 1024 | 1536 × 2048 | 2480 × 3312 |
| **16:9** | 1536 × 864 | 2048 × 1152 | **3840 × 2160** |
| **9:16** | 864 × 1536 | 1152 × 2048 | **2160 × 3840** |
| **21:9** | 2016 × 864 | 2688 × 1152 | **3840 × 1648** |
| **9:21** | 864 × 2016 | 1152 × 2688 | **1648 × 3840** |

待验收：

- 在画布和图像工作台逐项切换 3 档分辨率与 9 种比例，W/H 应与表格一致，重新打开设置后仍选中正确档位；重点检查 1K 的 2:3、16:9、21:9 及对应竖图，以及 4K 的 1:1。
- 所有 4K 预设提交时均不应触发本地总像素或最长边限制；生成和编辑请求、调用脚本应收到所选像素尺寸。
- 分辨率为自动时保留比例选择，比例为自动时禁用 W/H；手动输入 W/H 后，对齐开关仍应按原有方式工作。
- Gemini 请求应带 aspectRatio（所选比例）；分辨率选了 1K / 2K / 4K 时应按尺寸表带上 imageConfig.imageSize，选自动时不带。质量不参与分辨率换算，视频尺寸设置保持原有行为。
- 图像质量可选自动与 5 档（低 / 中 / 高 / 极高 / 最高），请求里的 quality 字段应与所选档位一致，且尺寸不随质量变化。
- Assistant wording: the canvas connection status, agent panel status and hints, Skill manager, permission mode, and runtime log titles no longer show "Codex" and read "Assistant" instead, with the meaning of connected, running, approval, and failure states unchanged.
- Built-in Agnes video script: the default-channel `agnes-video-2.5` / `agnes-video-2.5-flash` models should start a generation without the `Cannot read properties of undefined (reading 'length')` error; text-only runs use `mode: text`, one or two images use `mode: keyframe` with `first_frame` / `last_frame`, three or more use `mode: reference` with `images`, and the result is polled through `/agnesapi` with `video_id` + `model_name`, reading the top-level `url`. Reference images (data URLs) and reference audio (local files converted to data URLs) should upload directly, while reference video still needs a publicly reachable URL and should report that clearly. Whether `agnes-video-2.5` is available depends on the account group; when it is not enabled the API returns a model-not-supported error, so verify with `agnes-video-2.5-flash` first.
